# Drinkins (merged)

Single site with a theme switch in the nav:
- **Forest** (default): green palette, Inter font, green bottle (from Drinkins)
- **Amber**: orange/cream palette, DM Sans font, amber bottle (from animated-bottle-scroll)

The choice is remembered in localStorage. Static site: deploy the folder as-is on Vercel (Framework: Other, no build command, output directory: root).
